SciGraph AI — Mathematical Formulas & Architecture

Interactive, Clean Reference Document for Seminar Presentation

1. End-to-End System Architecture Flow

1
OpenAlex Bibliographic Ingestion: Retrieves genuine paper metadata (Publication Year, Authors, Citations, Institutions).
2
Observation Freeze (T_cutoff = Y_pub): Slices historical arrays. All future citations post-publication are strictly masked to guarantee zero leakage.
3
Feature Extraction (Vector x): Assembles a 5-dimensional normalized numerical vector.
4
PyTorch GraphSAGE Forward Pass: Passes vector through a 64-neuron hidden layer + ReLU activation + 3-class Softmax layer.
5
Dynamic Cohort Classification: Selects predicted tier (Low <50%, Medium 50-90%, High ≥90%).

2. Deep Dive: The 5 Extracted Features

Feature Exact Formula Why We Extracted This? What It Tells the Model
x0: Normalized Year x0 = (PubYear - 2012) / 10 Publishing velocity changes over decades. Anchors paper in its temporal era ([2012-2022] → [0.0, 1.0]).
x1: Scaled Early Citations x1 = Citations_cutoff / 100 Early pickup indicates immediate peer interest. Measures early adoption velocity normalized for neural gradients.
x2: Title Complexity x2 = Title_Word_Count / 20 Concise titles correlate with broad fundamental breakthroughs. Measures lexical scope and granularity of the paper.
x3: Author Team Ratio x3 = CoAuthor_Count / 10 Major breakthroughs are heavily collaborative. Indicates collaborative breadth and institutional reach.
x4: Log-Citation Velocity x4 = ln(1 + Citations_cutoff) Citations follow a heavy-tailed power-law distribution. Compresses extreme outliers so viral papers don't blow up weights.

3. PyTorch Neural Network Feed-Forward Equations

Step 1: Input Vector
x = [x0, x1, x2, x3, x4]^T ∈ ℝ5 × 1

Step 2: Hidden Layer Linear Transformation (64 neurons)
h1 = W1 · x + b1 [where W1 ∈ ℝ64 × 5, b1 ∈ ℝ64]

Step 3: Non-Linear Activation (ReLU)
a1 = max(0, h1) = ReLU(h1)

Step 4: Output Classifier Layer (Logits)
z = W2 · a1 + b2 = [z0, z1, z2]^T [where W2 ∈ ℝ3 × 64, b2 ∈ ℝ3]

Step 5: Softmax Probability Distribution (Sums to 100%)
P(Low Impact) = exp(z0) / [exp(z0) + exp(z1) + exp(z2)]
P(Medium Impact) = exp(z1) / [exp(z0) + exp(z1) + exp(z2)]
P(High Impact) = exp(z2) / [exp(z0) + exp(z1) + exp(z2)]

Step 6: Argmax Decision Rule
Predicted Class = argmax { P(Low), P(Medium), P(High) }

4. Dynamic Cohort-Normalized Impact Classes

We measure 5-year growth ΔCitations5 = Citations(Y+5) - Citations(Y) and compare against that year's cohort:

  • Class 0: Low Impact — ΔCitations < 50th Percentile (Bottom half of papers that year)
  • Class 1: Medium Impact — 50th ≤ ΔCitations < 90th Percentile (Mainstream solid contribution)
  • Class 2: High Impact — ΔCitations ≥ 90th Percentile (Top 10% Landmark Breakthroughs)
